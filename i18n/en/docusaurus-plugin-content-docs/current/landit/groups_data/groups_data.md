This video shows the interaction between the map and the groups data table, namely filtering and sorting in the table, highlighting on the map when selecting table rows (for example, selecting an owner highlights their properties on the map), viewing a property's main information by clicking it on the map, and jumping to the corresponding table row by double-clicking a property (or to the first one, if there are several).

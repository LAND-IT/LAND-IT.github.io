Version 6.1.0 of LAND IT is now available. Below is the list of changes and new features.

<!-- truncate -->

- Join and Info Layers:
    - Visual separation of layers in the attribute tables of a join layer
    - Ability to choose from among the various columns to display in a join layer.
    - Address validation and autocomplete.
    - Added a visual indicator (asterisk) to required attributes in the pop-up for adding/editing information layer rows.
    - Removed the ability to hide columns by dragging them outside the table (to prevent users from accidentally hiding columns).
    - Bug fixes:
        - Fixed an error that appeared in the front-end in the pop-up for adding an information layer.
        - Fixed an error that could occur when attempting to remove a layer from the map while the attribute table of a vector layer was open.
        - Error that occurred on the back end when attempting to edit rows without changing any values, or when merging two rows by selecting all attributes from a single row.
        - Error in which fields referenced in the pop-up for adding/editing information layer rows could appear multiple times (duplicated).
        - An error where exporting a table’s CSV file included an extra column (“visibility”).
        - An error that could occur when attempting to create merge layers.
        - Added some missing translations.
- Save the visibility state and style of layers after refreshing the page.
- New geoprocessing tool: Dissolve.
- View statistics for selected polygons only.
- In the “Set Polygon Properties” pop-up, under the “All” option, you can enter annotations individually.
- User management pop-up (Allows you to remove users and change their permissions).
- Correction of various bugs.

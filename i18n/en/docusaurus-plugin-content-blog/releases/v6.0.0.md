Version 6.0.0 of LAND IT is now available. Below is the list of changes and new features.

<!-- truncate -->

- Accession and info layers:
    - Creation of the JSON files that define the various membership-related layers, including the relationships between their attributes — Properties, Owners, Addresses, etc.
    - Creation of new attribute types in LAND IT allowing the complete import of membership CSV files.
    - Implementation of automatic validation mechanisms for various attribute types — Tax ID (NIF), CCH, Portuguese and international mobile numbers, emails, and Portuguese addresses.
    - Possibility to manually validate emails or addresses whenever automatic validation is not possible.
    - Possibility to merge two rows from the same information layer when, for example, two rows represent the same owner. In this menu, users can choose between the attributes of both rows and decide which ones to include in the final row.
    - If an information table contains the necessary attributes to formulate a complete address (according to CTT standards), an easy-to-spot button appears to display the address in letter format with the fields in the correct order.
    - When attempting to delete a layer that is referenced by other layers, a warning is displayed indicating which layers will be affected.
    - Only certain users, with specific membership permissions, can import, add, edit, and delete rows from the information layers.
- Map Layer Grouping:
    - Possibility to create layer groups and reorder these groups within the list.
    - Enable/disable all layers simultaneously or only the layers within groups.
    - Delete multiple layers simultaneously.
- Correction of various bugs.

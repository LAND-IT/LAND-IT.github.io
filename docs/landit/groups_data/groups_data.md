### Interação Mapa Tabela

Este vídeo mostra a interação entre o mapa e a tabela de dados de agrupamento, nomeadamente a filtragem e ordenação na tabela, o destaque no mapa ao selecionar linhas da tabela (por exemplo, selecionar um proprietário destaca as suas propriedades no mapa), ao clicar numa propriedade no mapa podemos ver a sua informação principal, a navegação para a linha correspondente na tabela com duplo clique numa propriedade (ou para a primeira, caso existam várias).

{<video style={{width:"100%"}} src={require('/videos/GroupsData/Tutorial 2 - Interação Mapa Tabela.mp4').default} controls/>}

### Barra de Pesquisa

Este vídeo mostra como utilizar a barra de pesquisa para pesquisar dados nas perspetivas, por exemplo, pesquisar um proprietário pelo NIF ou pelo nome, ou uma propriedade pelo NIC ou pelo PRD.
